> **Neural Network Encryption in C**

An experimental encryption system using neural networks and matrix inversion to encrypt and decrypt messages.

The original Windows version is included in the `windows-specific-version` folder. The main version has minor changes for Linux compatibility.

**How to Run**

Open the project folder in an IDE (I use CLion).

Build and run the `neural_network_encryption` target.

The program will encrypt and decrypt a sample message and print the results.

Note: Decrypted messages will contain extra characters at the end.
